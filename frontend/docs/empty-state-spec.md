# Empty State Spec

## Purpose

这份文档用于约定“普通账号 / 零数据账号”联调时应该返回什么，避免前端只能在 demo 数据下看起来正常。

---

## 1. Empty State Principle

空状态不等于报错。

联调时请区分：

- `loading`
- `error`
- `empty`
- `hasData`

前端希望后端在零数据时返回空数组或空对象，而不是 500 或字段缺失。

---

## 2. Student Empty State

适用场景：

- 刚注册学生
- 还未加入任何课程
- 某门课程暂无资料、暂无任务、暂无讨论

建议返回：

- Dashboard：统计为 0，课程数组为空，通知数组为空
- 课程页：`home` 可返回欢迎信息，其余列表为空数组
- AI：会话列表为空，但允许新建对话
- Learning：错题、闪卡、学习概览可返回空数组和 0 值

---

## 3. Teacher Empty State

适用场景：

- 新教师刚开通账号
- 还未创建课程
- 课程刚创建，暂无学生、暂无资料、暂无任务

建议返回：

- Teacher Dashboard：统计为 0，课程列表为空，通知为空
- 教师课程首页：可保留邀请码，统计为 0
- 学生管理：空数组
- 问答 / 讨论 / 任务：空数组
- 教师 AI 助教：问题队列为空、反馈为空、会话可为空

---

## 4. Admin Empty State

适用场景：

- 测试环境刚启动
- 审核队列暂时为空

建议返回：

- 待审核注册为空
- 用户列表可为空
- 课程列表可为空
- 审核报告可为空
- 系统设置仍建议返回默认值，而不是缺失

---

## 5. Recommended Empty Shapes

建议后端返回：

```json
{
  "items": []
}
```

或：

```json
{
  "stats": {
    "count": 0
  },
  "list": []
}
```

不要返回：

- `null` 代替整个对象
- 缺少前端已依赖的核心字段

---

## 6. Empty State Priority

联调优先保证这些页面在空状态下可用：

1. 学生 Dashboard
2. 教师 Dashboard
3. 管理员 Dashboard
4. 学生课程页
5. 教师课程页
6. 学生 AI 助教
7. 教师 AI 助教
